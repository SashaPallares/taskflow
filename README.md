# 📋 Taskflow — Gestor de Tareas Full Stack

**Taskflow** es una aplicación de gestión de tareas multi-tier diseñada con una arquitectura desacoplada, combinando un frontend ágil y responsivo con un potente servicio de backend desarrollado en Python con FastAPI.

## Características principales

- **Arquitectura Desacoplada (Decoupled):** Separación limpia entre el cliente y el servidor, facilitando la escalabilidad y el mantenimiento.
- **API de Alto Rendimiento:** Backend robusto impulsado por FastAPI para el manejo eficiente de operaciones y lógica de negocio.
- **Gestión Integral de Tareas:** Creación, organización, actualización y eliminación de tareas con persistencia en base de datos.
- **Interfaz Moderna:** Diseño limpio, intuitivo y adaptable a diferentes dispositivos.

## Tecnologías utilizadas

- **Backend:** Python, FastAPI, Uvicorn, bases de datos (MongoDB / SQLite según configuración).
- **Frontend:** React / JavaScript, HTML5, CSS3 / componentes personalizados.
- **Control de Versiones:** Git & GitHub.
